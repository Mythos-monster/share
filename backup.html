채팅 로그 시간순 백업

크롬 PC 환경 기준입니다. 사이트가 개편되면 작동하지 않을 수 있어요.

캐릭터챗을 오래 쓰면 대화가 길어져 따로 백업해두고 싶을 때가 있습니다. 그런데 페이지에서 전체를 블록 지정해 복사하면 사이트 구조상 순서가 역순으로 붙습니다. 아래 방법은 시간순 그대로 .txt 파일로 저장해줍니다.

  1. 대화를 전부 불러오기

    백업할 채팅방을 열고 Home 키로 페이지 맨 위까지 올라갑니다. 위로 올릴 때마다 옛 대화가 추가로 로딩되니, 잠깐 기다렸다가 다시 Home을 누르는 식으로 백업할 내용이 전부 화면에 불러와질 때까지 반복하세요.

    화면에 불러오지 않은 과거 대화는 파일에도 포함되지 않습니다.

  2. 개발자 콘솔 열기

    아래 단축키로 크롬 개발자 도구 콘솔을 엽니다. 화면 아래 > 오른쪽이 입력하는 곳이에요.

    Ctrl + Shift + J

  3. 붙여넣기 허용 (처음 한 번만)

    처음이면 붙여넣기가 막힐 수 있습니다. 이때는 아래 문구만 직접 입력하고 Enter를 누르세요.

    allow pasting

  4. 백업 코드 실행

    아래 코드를 통째로 복사해 콘솔 > 오른쪽에 붙여넣고 Enter를 누릅니다.

    (()=>{const c=[...document.querySelectorAll('.flex.flex-col-reverse')].sort((a,b)=>b.children.length-a.children.length)[0];const t=[...c.children].reverse().map(x=>x.innerText.trim()).filter(Boolean).join('\n\n');const b=new Blob(['\uFEFF'+t],{type:'text/plain;charset=utf-8'});const a=document.createElement('a');a.href=URL.createObjectURL(b);a.download='채팅로그_시간순.txt';a.click();setTimeout(()=>URL.revokeObjectURL(a.href),1000);console.log('저장 완료:',c.children.length+'개 덩어리',t.length+'자')})()

    정상 실행되면 복사·붙여넣기 없이 채팅로그_시간순.txt 파일이 자동 저장됩니다. 내용은 각 대화의 문단 구성을 유지한 채 가장 오래된 → 가장 최근 순서로 정리됩니다.

중요한 로그라면 저장 후 맨 위와 맨 아래 대화 시간이 올바른 순서인지 한 번씩 확인해두는 걸 권합니다.
